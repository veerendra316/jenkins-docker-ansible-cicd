Automated application deployment using GitHub, Jenkins, Docker, Amazon ECR, Ansible and AWS EC2.

```

Technology Stack

This application demonstrates an automated CI/CD workflow from source code commit to deployment on multiple AWS servers.

GitHub

Source code management and version control.

Jenkins

Automated CI/CD pipeline orchestration.

Docker

Containerized application build and testing.

Amazon ECR

Secure storage for Docker container images.

Ansible

Automated deployment and server configuration.

AWS EC2

Application hosting on cloud infrastructure.

```
```

CI/CD Pipeline

Every code change can automatically travel through the complete deployment pipeline.

01

Git Push

Developer pushes code to GitHub.

02

Webhook

GitHub triggers Jenkins automatically.

03

Build

Jenkins builds the Docker image.

04

Test

Container is started and tested.

05

ECR

Image is pushed to Amazon ECR.

06

Deploy

Ansible deploys the image to EC2.

```
```
